TASK NAME: Top Cool Votes

TASK OVERVIEW:
Find the review_text that received the highest number of cool votes.
Output the business name along with the review text with the highest number of cool votes.

DATA REQUIREMENTS:
* Table: yelp_reviews
* Columns:
  - business_name (text)
  - cool (bigint)
  - funny (bigint)
  - review_date (date)
  - review_id (text)
  - review_text (text)
  - stars (text)
  - useful (bigint)
  - user_id (text)
