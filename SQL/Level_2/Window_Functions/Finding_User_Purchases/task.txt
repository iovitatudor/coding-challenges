========================================================================
TASK NAME: Finding User Purchases
========================================================================

TASK OVERVIEW:
Identify returning active users by finding users who made a second purchase 
within 1 to 7 days after their first purchase. Ignore same-day purchases. 
Output a list of these user_ids.

DATA REQUIREMENTS:
* Table: amazon_transactions
* Columns:
  - created_at (date)
  - id (bigint)
  - item (text)
  - revenue (bigint)
  - user_id (bigint)
