========================================================================
TASK NAME: Matching Similar Hosts and Guests
========================================================================

TASK OVERVIEW:
Find matching hosts and guests pairs in a way that they are both of the same gender and nationality.
Output the host id and the guest id of matched pair.

DATA REQUIREMENTS:
* Table: airbnb_hosts
* Columns:
  - age (bigint)
  - gender (text)
  - host_id (bigint)
  - nationality (text)

* Table: airbnb_guests
* Columns:
  - age (bigint)
  - gender (text)
  - guest_id (bigint)
  - nationality (text)
