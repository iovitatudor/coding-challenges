========================================================================
TASK NAME: Products Report Summary
========================================================================

TASK OVERVIEW:
Find the total number of unique transactions and cumulative overall sales generated by each product category during the 2017 calendar year. Output the category name, transaction volume, and total sales revenue arranged in descending order based on sales performance. Exclude any categories with zero product units sold.

DATA REQUIREMENTS:
* Time Snapshot Filtering: Restrict calculation evaluation rows to transaction dates within the 2017 fiscal block ('2017-01-01' to '2017-12-31' inclusive).
* Table Association: Implement an INNER JOIN between the sales transaction log and the product dimension catalog to implicitly enforce the rule to only include active sold products.
* Multi-Metric Aggregation: Count unique transaction identifiers while concurrently summing the aggregate sales column for each unique category.
* Sort Ordering: Enforce a strict descending layout sequence based on the finalized total sales output field.
* Columns Needed: product_category, transaction_count, total_sales

TABLE SCHEMA:

1. wfm_transactions (t)
   - transaction_id (Big Int) — Unique tracking token generated at the register checkout.
   - product_id (Big Int) — Foreign key item mapping to the product directory catalog.
   - transaction_date (Date) — The calendar date the sale was finalized.
   - sales (Big Int) — The absolute final cost paid by the customer for that specific item.

2. wfm_products (p)
   - product_id (Big Int) — Unique identification key for the cataloged product item.
   - product_category (Text) — High-level classification label for the inventory item.
