========================================================================
TASK NAME: Order Details
========================================================================

TASK OVERVIEW:
Find order details made by customers with the first name 'Jill' or 'Eva'.
Output the order date, details, cost, and first name, ordered by
customer ID in ascending order.

DATA REQUIREMENTS:
* Tables: customers, orders
* Relevant Columns:
  - customers: id, first_name
  - orders: cust_id, order_date, order_details, total_order_cost

JOIN & FILTER CONDITIONS:
* INNER JOIN customers c ON c.id = o.cust_id
* WHERE c.first_name IN ('Jill', 'Eva')
* ORDER BY c.id ASC

EXPECTED OUTPUT FORMAT:
* order_date (date)
* order_details (text)
* total_order_cost (bigint)
* first_name (text)

========================================================================
