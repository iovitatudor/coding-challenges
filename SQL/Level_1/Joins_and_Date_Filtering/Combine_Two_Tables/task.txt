TASK NAME: Combine Two Tables
========================================================================

TASK OVERVIEW:
Report the first name, last name, city, and state of each person in the Person table.
If the address of a personId is not present in the Address table, report null instead.

DATA REQUIREMENTS:
* Table: Person
  - personId (int)
  - lastName (varchar)
  - firstName (varchar)
* Table: Address
  - addressId (int)
  - personId (int)
  - city (varchar)
  - state (varchar)
