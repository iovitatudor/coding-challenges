# Coding Challenges

A personal repository with solved programming problems, algorithms, and data structure exercises.

The purpose of this repository is to improve problem-solving skills, strengthen algorithmic thinking, and stay in good shape as a software developer through consistent practice.

## Goals

- Practice algorithms and data structures
- Improve analytical thinking
- Explore different approaches and optimizations
- Prepare for technical interviews
- Write clean and maintainable solutions

## Philosophy

The goal is not only to solve problems, but also to understand:
- why a solution works,
- how it can be optimized,
- and when a particular approach should be used.

Solutions aim to prioritize readability, maintainability, and complexity awareness whenever possible.

## Progress

This repository is continuously updated with new problems and solutions as part of ongoing learning and practice.
