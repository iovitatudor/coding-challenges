========================================================================
TASK NAME: Find the Duplicate
========================================================================

TASK OVERVIEW:
Given N integers where all numbers are between 1 and N-1, find and print
the single number that appears twice.

INPUT / OUTPUT:
* Input:
  - Line 1: N (number of elements).
  - Line 2: N space-separated integers.
* Output: Print the duplicate integer.

CONSTRAINTS:
- Numbers are within the range [1, N-1].
- Exactly one number is duplicated.

EXAMPLE:
* Input:
  5
  1 3 4 2 2
* Output: 2
